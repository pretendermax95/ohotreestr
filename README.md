# ОхотРеестр

Веб-приложение для ведения реестра охотников, документов и разрешений.

## Запуск

Откройте `index.html` в браузере или опубликуйте репозиторий через GitHub Pages.

Демо-доступ:

- Логин: `admin`
- Пароль: `admin`

Данные сохраняются в локальном хранилище браузера. Для общей базы между пользователями нужен серверный backend.
